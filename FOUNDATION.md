# Связь с Foundation

Foundation — система сохранения контекста между ИИ-исполнителями
и сессиями. Этот проект подключён к ней в минимальном виде.
Статус подключения: пробное, решение о принятии не принято.

- **Канон:** https://github.com/LuckyBait/Foundation @ commit 9557a3e4afcfb95d08388eac9dde069e11710373
- **Принимается из канона:** определения «Истина» и «Искажение» и три
  Закона из преамбулы CANON.md
- **Не применяется:** Process Check, Governance Backlog, ревью
- **Статус проекта:** README.md и CHANGELOG.md этого репозитория
- **Обратный канал:** практика этого проекта, которая может улучшить
  канон, фиксируется в governance/IDEAS_AND_DISCUSSION.md Foundation
  с пометкой «источник: Dispatching»

Как устроено подключение: governance/PROJECT_BOOTSTRAP.md в Foundation
(v0, пробный).
