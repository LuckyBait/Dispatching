# АРМ диспетчера на базе Текон АСУД.SCADA
### Раздел проекта: ИОС5.4 (Автоматизация и диспетчеризация инженерных систем)
### Роль: монтаж и ПНР систем вентиляции + сборка АРМ диспетчера

---

## Назначение репозитория

Рабочий архив по проекту: анализ исходной документации, справочные материалы Текон-Автоматика, схема интеграции по Modbus/RS-485, чек-листы ПНР и журнал решений. Ведётся по мере продвижения проекта.

## Структура

```
docs/
  01-project-summary.md          — анализ раздела ИОС5.4, состав оборудования, объём диспетчеризации
  02-tekon-scada-links.md        — ссылки на документацию TekonWiki по теме
  03-modbus-rs485-integration.md — протокол обмена, регистры, EXT-2, КУН-IP8
  04-commissioning-checklist.md  — чек-лист пусконаладки АРМ (физика/сеть/софт + проверка)
CHANGELOG.md                     — журнал решений и открытых вопросов по датам
```

Исходные PDF (проектная документация ИОС5.4, инструкция оператора АСУД.SCADA 2.7.0) в репозиторий не включены.

## Статус проекта

**Открытый вопрос (блокер):** таблица регистров Modbus для щитов "Смарт Контрол" (ООО «НТЦ Евровент», ШУ-С4Ч-S1000-00-01-IP31 и др.) — ожидается от поставщика/интегратора.

**Подтверждено:** архитектура диспетчеризации в проекте изначально построена на Текон АСУД.SCADA (АСУД-248, ОРС-сервер + KCSLogger + ASUDBase6, концентратор КУН-IP8, 9× драйверов EXT-2, блоки БУРР-1М/БИС-1М для VRV) — сторонней интеграции не требуется, всё в рамках штатной линейки производителя.

См. подробности в `docs/` и историю решений в `CHANGELOG.md`.

Связь с Foundation (сохранение контекста между ИИ-исполнителями): см. [FOUNDATION.md](FOUNDATION.md).
