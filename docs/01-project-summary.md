## Объём диспетчеризации (структурная схема, лист 16)

Шкаф АСУД (концентратор) объединяет по кабелю КВП 4х2х0,52:
- ШАиУ П1, П2, П3В4, П4 (приточная вентиляция)
- ШАиУ В1, В2, В3, В5, В6 (вытяжная вентиляция)
- сигналы АВР из ИТП / электрощитовой

Итого **9 систем вентиляции** — совпадает с количеством закупленных драйверов EXT-2.

Кондиционирование (VRV1.1–1.6, К1.1/К1.2, вероятно К7.1/К7.2) — через блоки БУРР-1М/БИС-1М по RS-485 (собственный протокол Текона, не Modbus).

Воздушно-тепловые завесы (лист 13) — только локальное управление, в диспетчеризацию не выведены.

## Щиты автоматики вентиляции

Производитель: ООО «НТЦ Евровент», серия "Смарт Контрол" (ШУ-С4Ч-S1000-00-01-IP31, ШУ-С1,1Ч-S0000-00-00-IP31 и др.)
В спецификации указана опция "Возможность подключения ШУ к системе диспетчеризации" — протокол в проекте явно не указан, физическая линия — RS-485 (обозначена на функциональных схемах, листы 9–12: "RS485 Диспетчеризация").

**Открытый вопрос:** нужна таблица регистров Modbus (или подтверждение протокола) от НТЦ Евровент — см. `docs-03-modbus-rs485-integration.md`.

## Риски / вопросы к заказчику

1. Windows XP для пульта АСУД-24 — снята с поддержки; уточнить, актуальна ли именно эта версия ПО или допустима более новая (см. версии SCADA 2.7–3.1 в TekonWiki).
2. Протокол обмена со щитами "Смарт Контрол" — нужен от НТЦ Евровент.
3. Полный перечень сигналов ввода-вывода по каждой системе (для карты тегов ASUDBase6) в текстовой части и функциональных схемах не полный — часть данных нужно запрашивать опросными листами.
