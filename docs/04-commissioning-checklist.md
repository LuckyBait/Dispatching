# 04. Чек-лист пусконаладки АРМ

## Этап 1. Щиты "Смарт Контрол" (на месте, до объединения в сеть)

- [ ] Выставить уникальный Modbus-адрес (slave ID) на каждом щите
- [ ] Настроить параметры порта (скорость/чётность/стоп-биты) — одинаковые на всей линии
- [ ] Зафиксировать адрес/настройки в таблице (для последующей регистрации в ОРС-сервере)

## Этап 2. Физическая линия RS-485

- [ ] Топология "шина" (не звезда), витая пара
- [ ] Соблюдена полярность A/B на всех устройствах
- [ ] Терминаторы 120 Ом на обоих концах линии (в т.ч. на КУН-IP8, если крайнее устройство — перемычки Term0/Term1)
- [ ] Общий провод (GND) подключён при необходимости

## Этап 3. Концентратор КУН-IP8 (предварительная настройка ДО подключения в боевую сеть)

- [ ] Подключить КУН-IP8 напрямую кроссовером к ноутбуку
- [ ] Зайти на заводской адрес http://192.168.1.100 (логин/пароль по умолчанию)
- [ ] Сменить пароль по умолчанию
- [ ] Прописать реальный статический IP-адрес под сеть объекта
- [ ] При необходимости настроить IP-фильтр/брандмауэр
- [ ] Подключить КУН-IP8 к сети 220В, убедиться в свечении PWR
- [ ] Подключить к коммутатору, убедиться в свечении LINK/ACT на RJ-45

## Этап 4. Диспетчерский ПК

- [ ] Вставить USB-ключ защиты с лицензией EXT-2 (число ≥ количества опрашиваемых устройств, у нас 9)
- [ ] Запустить конфигуратор ОРС-сервера (opcsrv.exe) от имени AdminScada
- [ ] Добавить КУН-IP8 в адресное пространство (DA Tekon → Добавить → КУН-IP8), указать его IP
- [ ] Дождаться статуса "online" (переключиться на другое устройство и обратно для обновления)
- [ ] Под КУН-IP8 добавить Modbus RTU устройство для каждого щита, загрузить/создать таблицу регистров
- [ ] Выполнить тестовый опрос ("Опросить") каждого устройства
- [ ] Оптимизировать запросы (увеличить число регистров в одном запросе, где возможно)
- [ ] Закрыть конфигуратор ОРС-сервера

## Этап 5. Проверка достоверности данных

- [ ] Для каждого сигнала — сверить с реальным состоянием на объекте (открыть/закрыть заслонку, посмотреть реальную температуру и т.п.)
- [ ] Убедиться, что значение в конфигураторе меняется синхронно с реальным

## Этап 6. АСУД.SCADA

- [ ] Проверить все теги через "Дополнительно / Сигналы ОРС-сервера" (без отрисовки карты)
- [ ] Разместить примитивы на ситуационном плане (вручную или через Шаблон-Концентратор)
- [ ] Настроить приоритеты и уведомления по авариям
- [ ] Сохранить конфигурацию карты, сделать резервную копию (папка `..\Scada\settings`)

## Типовые проблемы и диагностика

| Симптом | Проверить |
|---|---|
| КУН-IP8 не пингуется | Питание, подключение к коммутатору, правильность заданного IP |
| Статус устройства "offline" в ОРС-сервере | IP-адрес в настройках совпадает с реальным; нет конфликта IP с другим устройством |
| Ошибка при опросе Modbus-устройства | Кнопка "Лог" в окне устройства — код ошибки; проверить адрес/скорость/чётность на щите |
| Данные приходят, но "мусор" | Неверный Формат (порядок байт) — см. `docs-03-modbus-rs485-integration.md` |
| Не опрашивается ни одно устройство на линии | Рассогласование параметров порта у одного из щитов — ошибка "стопорит" всю шину |
